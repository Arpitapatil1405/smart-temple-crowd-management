# Smart Temple Crowd & Queue Management System — UI Prototype

A frontend-only prototype inspired by the provided design references.

## Run it
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No build step or package installation is required.

## Included
- Landing page with temple hero section
- Devotee dashboard and searchable temple cards
- Demo darshan booking flow and printable pass
- Live crowd-status page with clearly labelled demo data
- Emergency SOS, Donation, Parking, and Lost & Found modals
- Temple admin queue preview and main-admin token registry preview
- Responsive layout for desktop and mobile

## Important
This is a UI prototype only. Authentication, database persistence, real booking capacity checks, QR validation, payments, emergency dispatch, live camera/AI detection, and real queue operations are not implemented. The QR-style pattern is decorative and not a valid ticket. Demo data may reset when the page reloads.
